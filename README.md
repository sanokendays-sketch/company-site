# スカイライン・テクノロジーズ 企業サイト

業務システム開発・クラウド導入・AI活用支援を行うソフトウェア開発会社「スカイライン・テクノロジーズ（Skyline Technologies）」のコーポレートサイトです。

`index.html` 1ファイルで構成された静的サイトで、CSS と JavaScript もファイル内に記述しています。ビルドやサーバーは不要です。

## ページ構成

| セクション | 内容 |
|---|---|
| お知らせ | 最新ニュース |
| ヒーロー | キャッチコピーと無料相談への導線 |
| 私たちについて | 企業理念・ビジョン |
| 事業内容 | 業務システム開発 / クラウド導入・移行 / AI・データ活用支援 / Webアプリケーション開発 / モバイルアプリ開発 / 保守・運用サポート |
| 導入事例 | 物流・医療・小売の事例紹介 |
| 開発の流れ | ご相談から運用までのステップ |
| 会社概要 | 会社情報 |
| 採用情報 | 採用メッセージ |
| お問い合わせ | 問い合わせフォーム |

### 主な機能

- スマートフォン対応のレスポンシブデザイン（モバイル用ハンバーガーメニュー）
- スクロールに合わせたフェードイン表示と数値のカウントアップ
- お問い合わせフォームの入力チェック

> **注意:** お問い合わせフォームはデモ用です。送信ボタンを押してもデータはどこにも送信されません。

## ブラウザで index.html を開く手順

### 方法1: ファイルを直接開く（もっとも簡単）

1. エクスプローラーでこのフォルダ（`company-site`）を開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ（Chrome / Edge など）でサイトが表示されます。

ほかのブラウザで開きたい場合は、`index.html` を右クリックして「プログラムから開く」でブラウザを選ぶか、ブラウザのウィンドウへファイルをドラッグ＆ドロップしてください。

### 方法2: コマンドから開く

PowerShell でこのフォルダに移動して、次のコマンドを実行します。

```powershell
start index.html
```

### 方法3: ローカルサーバーで表示する（任意）

本番に近い環境で確認したい場合は、簡易サーバーを起動してください（Python が必要です）。

```bash
python -m http.server 8000
```

起動後、ブラウザで <http://localhost:8000> を開きます。終了するときはターミナルで `Ctrl + C` を押します。

> フォント（Noto Sans JP / Inter）は Google Fonts から読み込みます。オフライン環境では代替フォントで表示されます。
